# P.E.T.E.R. — Mobile (PWA)

A phone-friendly, installable web app that talks to the same Peter voice
assistant as the desktop orb. It connects to Peter over LiveKit, so saying
"play my music" starts Spotify on whatever device is active — including your
phone's Spotify app.

Everything the desktop app can do is here **except screen sharing** (which
doesn't make sense on a phone). That includes:
- 🗣️ **Voice conversation** with Peter (tap the orb).
- 🔗 **URL slot** — paste a link, say **"go peter"**, and Peter acts on it.
- 🎧 **Spotify** — link your account, pick a default playlist, say
  **"play my music"**.
- 📁 **Files** — upload a file (e.g. your resume) and ask Peter to read it.
- 💬 **Chat transcript** — Peter's replies appear as text below the orb.
- 🧠 **Memory** — long-term memory across sessions.

## What's here

| File | Purpose |
|------|---------|
| `index.html` | The mobile web UI (orb, URL, Spotify, files, chat). |
| `manifest.json` | PWA manifest (icons, standalone, orientation). |
| `sw.js` | Service worker (offline shell + network-first for live data). |
| `icon-192.png` / `icon-512.png` | App icons (generated by `generate_icon.py`). |
| `generate_icon.py` | Rebuilds the icons if you want to tweak the look. |

## Two ways to run it

### 1. Local (same Wi-Fi, PC on)
Served by `mobile_backend.py` (FastAPI). From the project root:
```
python mobile_backend.py
```
It serves the UI on `http://<your-pc-ip>:9094` (PC and phone on the same
network). Open that URL on your phone, then **Add to Home Screen** to install
it as an app. The desktop P.E.T.E.R app does **not** need to be open — the
backend auto-starts the Peter worker.

### 2. Cloud (one public link, PC can be off) ⭐ recommended
Deploy the whole thing (UI + API + Peter worker) to a free cloud host so it
works from anywhere even when your computer is off. There is exactly **one
link**:

- See **[DEPLOY_CLOUD.md](../DEPLOY_CLOUD.md)** for full step-by-step
  instructions (Render is easiest).
- The `Dockerfile`, `.dockerignore`, and `render.yaml` in the repo root are
  already set up for one-click container deployment.

## Requirements

- `fastapi`, `uvicorn`, and `psutil` (in `requirements.txt`).
- In **cloud mode**, the Peter worker runs inside the same container — no
  need to run anything on your PC.
- For "play my music" to play on the phone, have the **Spotify app open** on
  the phone (background is fine). Peter's playback code prefers the active
  phone/Spotify device first.
